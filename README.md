# מעקב חיפוש עבודה: תוסף לכרום

## התקנה (פעם אחת)
1. מורידים את הקוד: בעמוד הזה ב-GitHub לוחצים על **Code ← Download ZIP** ופותחים את הקובץ, או מריצים `git clone https://github.com/michal-Samson/job-tracker.git`
2. פותחים בכרום את הכתובת `chrome://extensions`
3. מדליקים את **Developer mode** (מצב מפתח) בפינה הימנית העליונה
4. לוחצים על **Load unpacked** ובוחרים את התיקייה שהורדתם (זו שיש בה את הקובץ `manifest.json`)
5. לוחצים על אייקון הפאזל 🧩 בסרגל של כרום ומצמידים 📌 את "מעקב חיפוש עבודה"

## שימוש
- **הוספת משרה:** בדף של משרה לוחצים על אייקון התוסף. הלינק, שם החברה והתפקיד מתמלאים לבד, ואפשר לתקן לפני השמירה.
- **הטבלה המלאה:** בחלון של התוסף לוחצים על "לטבלה המלאה". אפשר גם ללחוץ על האייקון בכפתור ימני ולבחור "אפשרויות".
- **פרטי משרה:** הטבלה מציגה רק את העיקר. לחיצה על שורה פותחת את כל הפרטים לעריכה, כולל היסטוריית הסטטוסים ומחיקה. לחיצה על שם החברה פותחת את המשרה עצמה.
- **שינוי סטטוס:** ישירות מהטבלה. כשבוחרים "הוגש", תאריך ההגשה מתמלא אוטומטית.
- **פולואפ:** משרה בסטטוס "הוגש" או "בבדיקה" שלא עודכנה 7 ימים מסומנת בכתום.
- **צעד הבא:** בעריכת משרה אפשר לרשום תאריך ומה צריך לעשות (ראיון, לחזור אליהם וכו'). כשהתאריך מגיע, המשרה מסומנת בטבלה.
- **מספר על האייקון:** מראה כמה משרות מחכות לפעולה (פולואפ, או צעד הבא שהגיע זמנו).
- **סטטיסטיקות:** בתפריט "עוד". כמה הגשות קיבלו תשובה, הזמן הממוצע עד תשובה, ופילוח לפי מקור ולפי גרסת קו"ח. כל שינוי סטטוס נשמר עם תאריך, ואפשר לראות את ההיסטוריה בחלון העריכה.
- **קשרים בלינקדאין:** בתפריט "עוד" בוחרים "ייבוא קשרים מלינקדאין" (ההוראות מופיעות שם). אחרי הייבוא, כל משרה מראה כמה קשרים יש לך בחברה, וכפתור מעתיק הודעה מוכנה לשליחה.

## חשוב לדעת
- הנתונים נשמרים **רק בדפדפן הזה במחשב הזה**. כדאי ללחוץ מדי פעם על "עוד" ואז "גיבוי נתונים".
- אם מוחקים את התוסף, הנתונים נמחקים איתו. לכן קודם כול גיבוי!
- אחרי שינוי בקוד, לוחצים על 🔄 ליד התוסף בעמוד `chrome://extensions`.

## רוצים לתרום?
מוזמנים לתקן באגים, לשפר או להוסיף דברים. אם יש רעיון או באג ואין לכם זמן לכתוב קוד, אפשר לפתוח **Issue** בלשונית Issues.

**איך שולחים שינוי:**
1. לוחצים על **Fork** בראש העמוד. זה יוצר עותק של הקוד בחשבון שלכם.
2. מורידים את העותק למחשב: `git clone https://github.com/<השם-שלכם>/job-tracker.git`
3. פותחים ענף חדש לשינוי: `git checkout -b short-name-for-the-change`
4. טוענים את התיקייה בכרום כמו בהתקנה למעלה, משנים את הקוד, ובודקים שהכול עובד. אחרי כל שינוי לוחצים על 🔄 ליד התוסף בעמוד `chrome://extensions`.
5. שומרים ומעלים: `git add -A`, אחר כך `git commit -m "מה שיניתי"`, ואז `git push -u origin short-name-for-the-change`
6. ב-GitHub יופיע כפתור **Compare & pull request**. לוחצים עליו, כותבים מה שיניתם ולמה, ושולחים.

**כמה דברים על הקוד:**
- אין כאן התקנות או שלב בנייה (build). זה HTML, CSS ו-JavaScript רגילים, וכרום טוען אותם ישירות.
- הממשק בעברית ומימין לשמאל, וכל טקסט חדש צריך להיות בעברית.
- כל הגישה לנתונים עוברת דרך `Store` שבקובץ `shared.js`. בשינויים במבנה הנתונים חשוב לשמור על תאימות למשרות שכבר שמורות אצל אנשים ולקבצי גיבוי ישנים.
- כל טקסט של המשתמש שמוצג בדף צריך לעבור דרך `esc()`.
- בשינוי קטן וממוקד קל יותר לבדוק ולמזג. אם מתכננים שינוי גדול, כדאי לפתוח קודם Issue ולהתייעץ.
